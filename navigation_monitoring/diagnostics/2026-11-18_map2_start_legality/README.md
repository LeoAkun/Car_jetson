## Nav2 如何判定非法

Smac Hybrid planner 把当前位置转换为全局代价地图的 `(x cell, y cell, angle bin)`。当前角度分 64 档，每档 5.625°；车体原始 footprint 为前后 `±0.43 m`、左右 `±0.28 m`，加 `0.02 m` padding 后约为 `±0.45 m × ±0.30 m`。

以下任一条件成立，起点都无效：

1. 位姿超出全局代价地图；
2. `allow_unknown=false` 时中心或足迹落入 unknown；
3. 中心格代价为 inscribed `253` 或 lethal `254`；
4. 按角度旋转后的矩形足迹边界栅格触碰 lethal `254`。

它检查的是 static、obstacle、inflation 等层叠加后的实时全局代价地图，不是只检查 `map2_clean.pgm`。因此现场空旷或静态 PGM 为白色，仍可能因实时层中的瞬时格而报非法。

11:54:10 起始位置约为 `(-207.79, 80.18, 78.62°)`。最近发布的全局代价地图中中心格代价为 61，足迹采样没有 `254/255`，随后确实成功生成路径；静态 PGM 中车体中心距最近占据格约 3.51 m。

第一次非法位置约为 `(-204.50, 90.14, 66.81°)`，静态 PGM 中车体中心距最近占据格仍约 3.16 m，远大于约 0.54 m 的足迹外接半径。因此 11:54:41 这次不是静态 PGM 中的墙或路沿造成。该格在前后 1 Hz 发布的完整 costmap 中都已清除，说明它是内部更新周期里的瞬时状态；本结论不继续归因到雷达回波。
