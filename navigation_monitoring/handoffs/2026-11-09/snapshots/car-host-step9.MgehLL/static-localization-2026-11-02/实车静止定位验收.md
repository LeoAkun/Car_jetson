# 实车静止定位检查 · 2026-11-02

**结论：通过本次静止定位检查。** 车辆在 3b2mus 已建图区域，实际速腾点云与旧地图成功匹配，独立复核的后续点云也与同一位置一致。定位后 map 坐标下的位姿保持厘米级稳定，没有明显跳变。

测试使用真实 RSHELIOS 点云、IMU、GPS 和项目当前安装的 LIO-SAM、NDT 重定位程序。测试 ROS 图限制在本机 `ROS_DOMAIN_ID=89` / `ROS_LOCALHOST_ONLY=1`，没有启动 Nav2、底盘、ECU、CAN 或控制器，也没有发送速度命令。定位结束后，所有 8 个启动节点均以退出码 0 关闭；没有遗留传感器、定位、导航或 ECU 控制进程。

## 限制与后续

本轮没有测试运动中的去畸变、转向时的时序误差、Nav2 接收初始位姿后的动作，也没有测量地图坐标的绝对真值。GPS 只作为约略搜索中心，最终位姿由点云与 3b2mus 地图匹配决定。以上结果确认车辆当前静止定位稳定，不能外推为运动导航或硬件时间同步已验收。

检查时发现生产自动初始定位的分数门槛过宽：NDT 参数 `score_threshold=2.0`，而分数定义范围为 0 到 1；`nav2_init_pose` 还会接受 `final_score<10.0`。本次手动约束的 NDT 候选通过独立点云重合验证，但没有启动生产自动初始化，因此不把它当作已验证。进行低速移动前应收紧自动初始化门槛并补上拒绝错误匹配的测试。

建议下一步：在 3b2mus 区域保持当前静止状态下，先验证生产 `nav2_init_pose` 能否从实际 GPS 和地图自动收敛并发布正确 map→odom；收紧拒绝条件、确认初始化结果和 TF 后，再做封闭场地低速直线短程及停车检查。此次定位测试用过的进程已全部停止。
