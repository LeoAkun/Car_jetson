# 普通导航速度单位修复：2026-11-06

**软件修复、构建和本机安装更新已完成；安装版本54项离线测试通过。尚未进行实车响应验证。** 本轮没有启动或重启车辆节点，没有启动导航、录包、回放或发送任何车辆控制/制动命令。

## 修复后的行为

普通导航输入 `Twist.linear.x` 以m/s解释，写入 `Ecu.motor` 时统一乘3.6换算为km/h。转角计算使用有符号的SI请求速度，电机偏置不再进入转角公式。

转换器增加普通模式最终速度上限0.8333333333333334m/s，对应3km/h。先判原始请求是否停车，再做低速补偿和前进偏置，补偿后也受上限约束。该上限覆盖导航、恢复和网页遥控经转换器输入的命令；直接发布 `/ecu` 或人工遥控不属于这个限制范围。

| 项目 | 修复后的值/行为 |
|---|---|
| 普通导航目标上限 | ±0.8333333333333334m/s，即约±3km/h |
| 生产低速补偿 | 0.2222222222222222m/s，对应原0.8km/h |
| 未带YAML启动的默认低速补偿 | 0.08333333333333333m/s，对应原0.3km/h |
| 前进偏置 | 0.008333333333333333m/s，对应原0.03km/h |
| 普通配置停车死区 | 0.005555555555555556m/s，对应原0.02km/h |
| 正反向停车阈值及零请求 | 均不被偏置抬起，最终速度归零并选择N档 |
| 充电对接 | 保留独立0.10m/s上限及3.6换算，不叠加普通模式低速补偿 |

普通请求+0.25m/s输出0.93km/h（含保留的0.03km/h偏置），−0.25m/s输出倒车0.90km/h。对接请求−0.03m/s仍为倒车0.108km/h。最高普通目标为3km/h，包含前进偏置，不再随偏置超过该值。

实车Nav2 MPPI与velocity_smoother的线速度上下限同步迁移；MPPI线速度采样标准差由1.5调整为1.5/3.6m/s。smoother平移加减速由2.5调整为2.5/3.6m/s²，保持原速度编码对应的物理范围。角速度、距离、时间、转弯半径和仿真配置未改变。当前本地MPPI不读取 `ax_max/ax_min`，这些配置字段虽同步迁移，生效的加减速约束来自smoother。
