# 实车测试聊天与代码修复聊天交接约定

本目录用于“只测试和记录”的聊天向当前代码修复聊天交接结果。

- 测试聊天不得修改源码、启动文件、参数或已安装程序。
- 每轮测试在 `history/` 下新建带日期时间的 Markdown 记录。
- 每轮结束后更新 `LATEST.md`，写明记录文件绝对路径、测试时间、是否进入有效导航、关键时间点、结论、未解决问题和建议代码检查项。
- 原始日志和录包仍放在对应的 `navigation_monitoring/runs/<时间>/` 目录；这里仅保存索引和结论。
- 代码修复聊天读取 `LATEST.md` 和对应历史记录后决定是否修改代码。
