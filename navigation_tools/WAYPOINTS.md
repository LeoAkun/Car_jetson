# 导航航点索引

坐标采用各地图的 `map` 坐标系：`+X` 向东/图右，`+Y` 向北/图上。方向表示车辆到点时的目标车头朝向。

派单时可以使用完整名称或“地图 + 编号”。历史数据中的编号可能跨地图重复；目录出现歧义时，工具会要求补充地图或完整名称。

当前自动工具只派发同一地图任务。历史 MQTT 日志没有打印地图切换点的 `next_x/next_y/next_yaw`，在补齐这些数据前不会猜测跨地图位姿。

## 工具命令

```bash
# 查询
python3 navigation_tools/dispatch_navigation.py list --map 3b2mus
python3 navigation_tools/dispatch_navigation.py show 108 --map 3b2mus

# 只检查路线，不启动ROS
python3 navigation_tools/dispatch_navigation.py plan 108 --start 106 --map 3b2mus

# 启动管理栈、监测器并派单
navigation_tools/start_navigation.sh 108 --start 106 --map 3b2mus

# 省略 --start 时，从实时GNSS选择目标地图内最近的安全航点
navigation_tools/start_navigation.sh "机车博物馆路口" --map 3b2mus
```
