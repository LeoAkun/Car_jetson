 路线切换功能实现方案                                                                                                                                                                                               
                                                        
 Context                                                                                                                                                                                                            
                                                                                                                                                                                                                    
 当前系统在导航失败时直接中止(abort)，车辆卡住时只能请求远程驾驶。需要增加自动切换备选路线的能力：当 Nav2 导航失败或车辆长时间卡住时，自动尝试下一条备选路线。                                                      
                                                                                                                                                                                                                    
 整体思路                                                                                                                                                                                                           

 基于 test.py 的 NetworkX 图搜索算法，预先计算多条备选路线。导航失败时依次尝试，全部用完再 fallback 到现有的中止/远程驾驶逻辑。

 需要新建的文件

 1. route_planner.py — 路线规划模块（纯 Python 类 + ROS2 包装）

 路径: src/multi_map_navigation/multi_map_navigation/route_planner.py

 核心类 RoadNetworkGraph（不依赖 ROS2，可独立测试）：
 - load_from_yaml(path) — 从 YAML 加载图
 - build_graph() — 构建 nx.Graph，节点带 waypoint 属性，边带 weight
 - compute_routes(source, target, max_routes=5) — 用 nx.shortest_simple_paths 计算多条路径
 - get_route_waypoints(route_index) — 将路径节点转为 Waypoint 列表
 - get_next_route() — 返回下一条备选路线
 - has_more_routes() — 是否还有备选

 ROS2 包装：RoutePlannerNode(Node) 提供两个 service：
 - /route_planner/plan_routes — 初始化任务，计算所有路线
 - /route_planner/get_next_route — 获取下一条备选路线

 数据流

 正常流程:
   MQTT任务 → mqtt_task_receiver → /waypoint_list
   → navigation_manager 调用 PlanRoutes 服务 → 获取第1条路线 → 开始导航

 Nav2失败切换:
   Nav2 返回失败 → nav2_result_callback
   → attempt_route_switch("nav2_failure")
   → 关闭导航栈 → 调用 GetNextRoute → 获取第2条路线 → 重启导航

 卡住检测切换:
   status_reporter 检测速度=0超时
   → 发布 RouteSwitch 到 /route_switch_request
   → navigation_manager 收到 → attempt_route_switch("stuck_detected")
   → 同上流程

 全部路线耗尽:
   GetNextRoute 返回 all_routes_exhausted=True
   → abort_navigation() → 发布 idle 状态
   → status_reporter fallback 到远程驾驶
