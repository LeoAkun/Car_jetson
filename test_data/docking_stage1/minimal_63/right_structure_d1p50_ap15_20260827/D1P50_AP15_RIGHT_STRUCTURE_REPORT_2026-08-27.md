# 阶段 1 最小矩阵：1.50 m / +15 deg 右侧桩体结构报告

车辆工况：`base_link -> dock_reference` 标称 `1.50 m`，车尾朝右约 `15 deg`（正角），车辆静止。目标始终选择雷达扫描前方右侧充电桩平面。

## ROI 与目标确认

- 实时扫描发现右侧连续段约 `54.2~77.2 deg`，径向中值约 `1.39 m`。
- 相邻 `42.2~53.7 deg` 段径向约 `1.16 m`，作为其他结构排除。
- 正式 ROI：`[56,75] deg`，中心 `65.5 deg`，半宽 `9.5 deg`。
- `expected_range_m=1.39 m` 仅用于径向目标段选择；最终距离应使用拟合平面法向距离。
- 当前三包拟合法向距离约 `1.2464 m`，这是观测值，不是人工真值。需人工测量“后雷达扫描旋转中心到右侧桩面垂直距离”后，写入 `expected_plane_normal_distance_m` 再做最终准确度验收。
