- 实际测试以 `dry_run:=false calibrated:=true auto_start:=false` 启动，并由测试客户端调用 `/standalone_docking/start`。

## 证据

- 有效观测的充电面纵向距离从约 `2.494 m` 变化到 `2.353 m`，说明车辆相对桩体发生了约 `0.14 m` 的移动；这是雷达估计，非独立测量的行程。
- `VehicleStatus.cur_speed` 全程为 `0`，但轮速反馈出现倒车速度；独立里程计因此没有积分平移，目标相对 P0 的深度门限最终被触发。
- 测试过程中未达到充电面，也未确认充电状态；程序失败后持续发布零速、空挡、刹车。

## 修正与验证

独立包在 `cur_speed == 0` 时改用左右轮速平均值；底盘驱动增加 `use_front_wheel_feedback` 配置，只使用新鲜 `0x168` 前轮反馈，防止诊断帧覆盖轮速。轮速过期、非法或与档位冲突时锁定停止。

修正后完成：

- 独立包测试：28 项通过，含零车速轮速回退、超出 P0 深度门限后的闭环对接，以及轮速中断停车。

- 修改的三个 Python 文件通过 `ament_flake8`；底盘驱动及独立包编译安装成功。
