2026-11-05，用户确认已将车辆停在指定 P0，授权启动一次独立自动对接测试。使用安装后的 `charging_dock_standalone`，参数为 `dry_run:=false calibrated:=true auto_start:=false`；先启动完整 bag 和记录器，再启动硬件，确认自动驾驶 ON、轮速为零、空挡制动及只有一个 `/ecu` 发布者，最后调用一次 `/standalone_docking/start`。未修改控制参数，未自动重试。

## 结果

**实际停距锁定已在实车生效，但未完成最终对接。** 停车后的稳定观测确认实际充电面距离 **0.933 m**，计算剩余倒车 **0.473 m**，预设停车触发距离仍为 1.000 m。锁定时横向误差 4.00 mm、角度误差约 0.456°，满足 5 mm / 0.5° 的门限。

进入 `LOCKED_FINAL_APPROACH` 后约 2.92 秒达到原有 90 秒总动作时限，以 `action_timeout` 停车。锁定后里程计净后退约 0.994 mm，停止时仍剩余 0.472 m；尚未验证走完整个里程计末段或在最终窗口完成充电对接。

## 低速推进

- t88～104.9：倒车指令约 -0.025 m/s，平均轮速约 -0.0209 m/s，轮速积分后退约 0.353 m。
- t120～127.806：同样约 -0.025 m/s，平均轮速仅约 -0.00257 m/s，轮速积分后退约 20 mm。
- t140.898～143.819（锁定末段）：平均轮速约 -0.000352 m/s，轮速积分后退约 1.03 mm，本地里程计 x 净减少约 0.994 mm。ECU 倒挡请求约 0.09，释放制动，但推进很弱。

这些数据提示需核对接近静止时的起步驱动力、底盘低速映射及制动释放响应；目前记录不能单独确定根因。总时限在锁定后已不足以完成剩余行程，单纯延长时限也不能保证克服几乎不动的低速响应。

`/cmd_vel_dock` 和 `/cmd_vel_selected` 的正向样本均为零，指令范围为 -0.06～0 m/s；短暂正轮速未触发方向故障。此次失败不是碰撞急停、锁定距离计算失效或完整桩体离开视场导致。
